# Helm API

Helm API is a planned intelligent LLM routing gateway. It accepts standard AI API requests, classifies task type and complexity, routes each request to a configurable lane, executes through provider adapters with fallback, and records full request/debug telemetry.

The repository currently stores product and technical specifications. Implementation will follow after the MVP scope is locked.
